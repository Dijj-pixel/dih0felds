# 🍽️ Felds

«Processador inteligente de pedidos de almoço.»

O Felds nasceu para resolver um problema simples, porém repetitivo: transformar listas de pedidos enviadas em conversas (como WhatsApp) em uma tabela organizada, padronizada e pronta para uso.

Em vez de copiar informações manualmente, corrigir nomes de pratos ou contar pedidos um a um, o Felds automatiza esse processo, reduzindo tempo e diminuindo erros humanos.

---

## 📖 Origem do nome

O nome Felds vem de feldspato, um dos minerais mais encontrados no ambiente em que o projeto foi desenvolvido.

O feldspato é um dos principais componentes da porcelana. A partir dessa associação surgiu a ideia:

«Feldspato → Porcelana → Prato → Refeição → Processamento de pedidos»

Assim nasceu o nome do projeto.

---

## 🎯 Objetivo

O objetivo do Felds é transformar informações desorganizadas em dados consistentes.

O sistema foi pensado para:

- 📋 Interpretar listas de pedidos.
- 🧠 Padronizar automaticamente informações.
- ⚠️ Destacar possíveis inconsistências.
- ✏️ Permitir correções rápidas.
- 📊 Gerar saídas prontas para utilização.

---

## ✨ Funcionalidades

Atualmente o sistema possui:

- ✅ Leitura de pedidos em texto.
- ✅ Extração automática de nomes.
- ✅ Identificação do prato solicitado.
- ✅ Reconhecimento de tamanhos.
- ✅ Captura de observações.
- ✅ Padronização automática de pedidos.
- ✅ Detecção de possíveis abreviações.
- ✅ Avisos visuais para revisão.
- ✅ Edição direta na tabela.
- ✅ Ordenação por nome.
- ✅ Ordenação por pedido.
- ✅ Exportação para Excel.
- ✅ Geração de resumo para compartilhamento.

---

⚙️ Como funciona

O fluxo do sistema pode ser resumido em:

```
Texto bruto
     │
     ▼
Leitura da conversa
     │
     ▼
Extração dos pedidos
     │
     ▼
Padronização
     │
     ▼
Validação
     │
     ▼
Correções (caso necessário)
     │
     ▼
Tabela organizada
     │
     ├──► Excel
     └──► Resumo
```
---

 ## 🧩 Filosofia

O Felds não tenta adivinhar tudo.

Sempre que possível ele realiza correções automáticas, porém quando existe qualquer dúvida, a decisão continua sendo do usuário.

A prioridade do projeto é auxiliar, e não substituir a revisão humana.

O projeto foi desenvolvido utilizando apenas tecnologias Web.

Isso permite executar o sistema diretamente no navegador, sem necessidade de instalação ou servidor.
